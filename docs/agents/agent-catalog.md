# Catálogo de agentes

## Nivel 0 — INFANTE

**Misión:** dirigir el programa, asignar tareas, priorizar entregables, controlar riesgos y aprobar la coherencia transversal.

**Puede:** crear y reasignar tareas, exigir validaciones, pedir aclaraciones, coordinar agentes y elevar decisiones al usuario.

**No debe:** inventar requisitos, aprobar por sí solo decisiones legales o laborales, ni exponer datos privados de una división a otra.

## Staff corporativo subordinado

| Agente | Especialidad | Salida principal |
|---|---|---|
| `CORP-HR` | políticas de personas y Employee Lifecycle | reglas y requisitos de RRHH |
| `CORP-LEARNING` | formación, versiones y aprobación | catálogo y gobernanza formativa |
| `CORP-QUALITY` | estándares, inspecciones y compliance | criterios de calidad |
| `CORP-FINANCE` | presupuestos, costes y controles | reglas financieras sintéticas |
| `CORP-GOVERNANCE` | autoridad, riesgos y decisiones | matriz de permisos y escalado |
| `CORP-DATA` | modelo común, métricas y auditoría | contratos de datos y audit events |
| `CORP-SECURITY` | privacidad, aislamiento y amenazas | controles de seguridad |
| `CORP-INTEGRATIONS` | APIs, webhooks y conectores futuros | contratos de integración |
| `CORP-PROGRAM` | planificación y dependencias | backlog y estado del programa |

## Nivel 1 — JANITORIAL

**Misión:** transformar contratos y necesidades de centros en servicios ejecutables, medibles y reportables.

**Puede:** gestionar operaciones, cobertura, contratos demo, presupuestos sintéticos, ofertas demo, empleados asignados, clientes de la división, calidad operativa y exportaciones preparadas.

**No puede:** acceder a datos de otras divisiones ni modificar políticas corporativas sin escalado.
