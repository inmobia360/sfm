# Contrato de integraciones

`integrations.html` presenta la arquitectura de conectores futuros: HRIS, payroll, calidad, flota, correo/calendario y CRM/cliente.

El MVP solo simula los puntos de conexión. No contiene credenciales, API keys ni llamadas externas. Cada integración productiva requerirá contrato de datos, autenticación, límites de acceso, reintentos, auditoría y aprobación de seguridad.
