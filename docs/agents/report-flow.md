# Flujo de informe para cliente

`report.html` representa el resultado visible de una semana de servicio: tareas, personal, inspecciones, calidad, incidencias y acción correctiva. Permite descargar JSON o CSV sintético y preparar una vista de impresión.

En producción, la publicación requerirá autorización del supervisor/CEO divisional y un portal de cliente con permisos limitados.
