# Guía de presentación de la demo

## Punto de entrada

Abrir `launch.html`. Desde ahí se accede a todas las vistas sin configuración ni credenciales.

En GitHub Pages, la URL de presentación será `.../sfm/launch.html` una vez que Pages esté habilitado para el repositorio y el workflow haya completado su primera ejecución.

## Recorrido recomendado

1. Abrir `scenarios.html` y presentar la historia del piloto.
2. Volver a `index.html` para explicar INFANTE y JANITORIAL.
3. Abrir `worker.html` y demostrar fichaje y checklist.
4. Volver a `scenarios.html` para mostrar calidad y payroll.
5. Abrir `audit.html` para cerrar con trazabilidad.

## Mensaje de cierre

SFM Operations Intelligence conecta personas, operaciones y dirección. El MVP no sustituye todavía payroll ni las herramientas existentes: crea una capa coordinadora y medible preparada para crecer por divisiones.

## Limitaciones declaradas

- Todos los datos son sintéticos.
- Geolocalización simulada y puntual.
- Payroll limitado a preparación/exportación de horas.
- IA representada mediante recomendaciones y aprobación humana.
- Sin autenticación, backend ni integraciones reales en esta entrega.
